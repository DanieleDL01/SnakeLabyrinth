# SnakeLabyrinth

A maze game developed in C as a university project.

## Features

- Manual maze navigation.
- Automated maze-solving algorithms.
- Obstacles, special tiles, and collectible coins.
- Scoring system.

## Requirements

- A C compiler, such as GCC.

## Compilation

```bash
gcc main.c -o SnakeLabyrinth
```

## Execution

On Windows:

```bash
SnakeLabyrinth.exe
```
